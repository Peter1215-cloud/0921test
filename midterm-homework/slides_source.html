PROJECT BACKGROUND & PROBLEM STATEMENT

🧭 專案緣起：東華人共同的世紀難題

校園佔地 250 公頃，每到用餐時刻，全校師生總是陷入重複的選擇障礙

🗺️
校地廣大 ╳ 資訊分散

東華校地全台第二大，涵蓋後門志學街、校內三大生活館（湖畔、集賢、多容）與前門，新生與一般同學難以即時掌握全盤美食資訊。

  • 各館舍學餐分散於南北兩端
  • 志學街巷弄隱藏許多老饕名店
  • 缺乏整合性的即時導航指南
🧠
心理情緒 ╳ 飲食慾望

用餐動機與情緒緊密連結！期中週熬夜趕報告渴望高CP值紓壓，心情愉悅時想吃大餐，平常時段則偏好家常懷舊小吃。

  • 傳統美食 App 只看店家分類（麵食/快餐）
  • 忽略學生當下「心情需求」與「預算痛點」
  • 無法精準命中此刻的生理與心理渴望
🌧️
花蓮天候 ╳ 外出安全性

花蓮東臨太平洋，氣候陰晴不定，傾盆大雨說來就來。大雨天騎機車或單車出校門極度不便且具交通安全風險。

  • 雨天迫切需要就近的校內學餐備案
  • 傳統搜尋引擎無法根據天氣自適應推播
  • 欠缺兼具人文關懷的天候安全提醒機制

DATA ENGINEERING & ARCHITECTURE

📊 資料庫建置與標籤特徵工程

深入田野調查 50 筆東華校園與志學街數據，建立結構化 CSV 資料庫

📁 數據結構設計 (restaurants.csv)

以 UTF-8-BOM 編碼標準儲存，保證在 Windows/Excel 環境下解析無亂碼，涵蓋 7 大核心屬性：

  • name (店名)：如香榭城、大理石廚房、湖畔餐廳、我家螺螄粉
  • type (料理型態)：便當快餐、早午餐/美式、麵食水餃、校內自助餐
  • mood (複合心情標籤)：以斜線 / 複合定義，多維度反映情感需求
  • weather (氣候適性)：出大太陽、陰天/涼爽、下大雨
  • price & location：價格級距（低、中、中高）與地理分區（志學街、校內）
  • description (特色描寫)：飽含東華在地生活記憶的精準生動短評

ENGINEERING CHALLENGES & TROUBLESHOOTING

🛠️ 開發實戰：工程挑戰與排錯經驗

跨越 Windows 編碼陷阱、動態佈局更新與例外防禦機制的實務解法

⚡
閃退危機：字碼頁亂碼

問題現象：雙擊捷徑時終端視窗一閃即逝，程式無法停留。

原因排查：Windows WScript.Shell 建立捷徑時，中文檔名受 ANSI 字碼頁干擾轉換為亂碼路徑；舊批次檔帶有 exit 導致秒退。

解決方案：全面改採純 ASCII run_app.bat，捷徑直接綁定 Python 直譯器，並加入 pause 恆久保持可見。

🔄
佈局殘留：Frame 銷毀機制

問題現象：多次點擊推薦或盲盒時，舊卡片與新卡片在容器內重疊破版。

技術根因：Tkinter Pack 管理器若未主動銷毀舊 Child Frame，會持續累積幾何計算快取。

解決方案：設計 _clear_cards_container()，先對容器內所有元件調用 destroy() 釋放記憶體後，再重新生成乾淨畫布。

🛡️
強健防禦：全域崩潰保護

工程規範：防止未預期錯誤造成使用者體驗中斷。

實作防護：在程式最外層注入 try-except 捕捉所有 Exception，除了自動保存 crash_report.log 外，自動彈出原生 messagebox.showerror 視窗，提供清晰排錯指引。
