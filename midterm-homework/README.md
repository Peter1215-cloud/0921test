# 東華校園美食情緒推薦系統（桌面完全版）🎓🍱

> 國立東華大學 AI 課程期中作業專案 (Midterm Homework Project)

---

## 📌 專案簡介
本專案為一套專為國立東華大學學生打造的本機桌面視窗應用程式（Desktop GUI App）。結合東華校園（湖畔、集賢館、多容館、管院）與志學街、前門周邊共 50 家經典店家數據，依據使用者當下的「心情 (Mood)」與花蓮的「天氣 (Weather)」進行智慧推薦，並提供一鍵 Google Maps 導航與命運抽籤功能。

---

## 🌟 核心特色與亮點

1. **現代感深色模式 (Dark Mode)**：
   - 使用 `CustomTkinter` 框架開發，具備高質感深色卡片風格與流暢排版。
2. **標籤動態萃取分析**：
   - 動態解析 `restaurants.csv` 中的複合標籤（支援 `/` 分隔），精準提取 10 種情緒維度與 3 種天氣狀態注入選單。
3. **智慧推薦 🚀**：
   - 雙條件多標籤篩選，超過 3 家時以隨機洗牌機制（`random.sample`）挑選 3 家高 CP 值/合適的美食。
4. **命運盲盒抽籤 🎲**：
   - 忽略下拉選單，從 50 家店中隨機抽選 1 家高亮呈現，解決東華人「今天吃什麼」的世紀難題。
5. **再換一組 🔄**：
   - 支援即時重新抽籤洗牌，卡片更新前徹底銷毀舊 Frame 元件，杜絕殘影與佈局閃爍。
6. **下雨天貼心彩蛋 🌧️**：
   - 天氣選為「下大雨」時，結果頂部自動高亮跳出關懷橫幅，提醒留在多容館、集賢館或湖畔等校內學餐用餐避雨。
7. **Google Maps 導航整合 🗺️**：
   - 每間餐廳皆自帶獨立導航按鈕，智慧區分校內店家（附加「東華大學」）與校外店家（附加「花蓮壽豐」），一鍵連動預設瀏覽器定位。

## 🚀 安裝與執行說明

### 1. 安裝套件依賴
確保已安裝 Python 3.10+，並在終端機安裝必要套件：
```bash
pip install -r requirements.txt
```

### 2. 啟動應用程式
- **方式一（Windows 批次檔）**：
  直接雙擊執行 `run_app.bat`。
- **方式二（終端機指令）**：
  ```bash
  python gui_app.py
  ```
